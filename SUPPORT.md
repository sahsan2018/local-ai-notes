# Support

Local AI Notes is pre-alpha and has no supported production deployment.

- Use GitHub Issues for reproducible bugs and narrowly scoped feature requests.
- Use GitHub Discussions, if enabled, for questions and broad design ideas.
- Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.

Before filing an issue, remove note contents, credentials, private hostnames, IP addresses, Tailnet names, mount paths, and other sensitive deployment details. Maintainers cannot guarantee response times.
